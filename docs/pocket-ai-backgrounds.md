# Pocket의 AI 배경·투명 원경

## 동작

Pocket 설정 → 장소 배경에서 현재 장소 또는 입력한 장소를 확인한다. 저장된 같은 장소를 먼저 찾고, 같은 장소 종류의 키워드가 맞으면 기존 이미지를 재사용한다. 예: 상담실 ↔ 심리상담센터 상담실 ↔ counseling room. 침실/상담실, 실내/야외, 집/집으로 돌아가는 길은 구분한다. 제작자가 첨부한 장소 별칭도 재사용에 반영된다. 현재 저장 범위는 **동일 사용자 + 동일 월드**이고 그 안의 여러 Pocket이 공유한다. 다른 사용자의 개인 장소 이미지와 섞지 않는다.

자동 생성은 처음에는 OFF다. ‘새 장소 자동 생성’을 켜면 재생되는 장소에 저장 이미지가 없을 때만 생성한다. ‘저장 배경 찾기 / 새로 만들기’는 수동 요청이다. 같은 장소의 기존 이미지가 있으면 이 버튼도 재생성하지 않는다. 직접 첨부한 이미지는 같은 장소의 AI 이미지보다 우선한다. 자동 생성을 끄더라도 이미 요청한 생성은 완료된다.

POST는 생성 작업을 등록하고 202를 반환한다. 한 서버에서 생성 작업 하나씩 처리하며 최대 16개를 대기한다. 파일 카탈로그 잠금 후 재확인해 중복 결제 요청을 줄인다. 생성은 대화/기억/시간/감정 DB 트랜잭션과 분리된다. 생성 실패에는 기본 프리셋을 유지하고 수동 재시도한다. 배경만 성공했다면 원경 재시도에서 그 배경 파일을 재사용한다. 재시작 후에도 완성 이미지와 미완성 배경은 디스크에 남는다.

## 크기와 레이어

기본 생성 모델은 gemini-3.1-flash-lite-image, 1K, 3:2다. 낮의 픽셀 아트와 비어 있는 캐릭터 공간을 요청한다. 240×160 논리 픽셀 PNG로 정리하고 nearest-neighbour로 확대한다. 작은 캐릭터의 기존 160px 내부 렌더와 비슷한 도트 밀도를 노린 선택이다. 실제 이미지의 구도·품질은 제공자 결과에 따라 검증해야 한다.

정사각 장면에서 배경은 화면 가로의 1.5배다. 300×300 내부 화면이면 450×300, 270×270이면 405×270이다. 화면의 중앙 부분을 보여주고 이동 시 가로 방향으로만 스크롤한다. 직사각 화면에서도 양 축을 덮고 3:2 비율을 유지한다.

배경(z=0) → 투명 원경(z=1) → 기존 3D 캐릭터(z=2) 순서다. 원경은 배경을 참고해서 같은 구도·팔레트로 만든다. 제공자가 진짜 alpha를 반환한다고 가정하지 않는다. 빈 부분을 순수 마젠타로 요청하고 서버에서 빈 공간과 구멍을 투명 PNG로 정리한다. 최소 10% 투명 공간과 최소 1% 그림이 있어야 통과한다. 불투명 원경은 적용하지 않는다. 배경 4초, 원경 7초 주기로 같은 방향으로 스크롤해 깊이감을 준다. 모션 줄이기 설정은 기존처럼 적용한다.

직접 첨부는 3:2 PNG/JPEG 배경과 alpha PNG 원경, 각 10MB 이하로 받는다. 파일을 디코딩해 크기/형식을 검사하고 같은 논리 픽셀 규격으로 저장한다. SVG 및 외부 URL 업로드는 받지 않는다.

## 생성 비용 비교 (2026-10-13)

| 방식 | 이미지 두 장 출력 비용 | 특징 |
|---|---:|---|
| Flash Lite Image 1K 원본 그대로 표시 | 약 $0.0672 | 작은 화면에서는 미세한 디테일이 도트 캐릭터와 어긋날 수 있음 |
| Flash Lite Image 1K → 240×160 → 픽셀 확대 (기본) | 약 $0.0672 | 생성비는 동일, 저장 용량과 도트 밀도에 유리 |
| Flash Image 512px → 픽셀 확대 | 약 $0.0900 | 낮은 해상도지만 현재 모델 단가가 더 높음 |

저비용 Lite 모델은 1K만 지원한다. 다운샘플링은 AI 생성비를 할인하지 않는다. 비용은 입력 토큰·재시도·세금을 제외한 출력 추정이다. 저장 이미지 재사용에는 생성비가 없다. 실패 후 재시도는 추가 호출 비용이 발생할 수 있다. 서버 디스크 용량 안에 파일로 저장하며 별도 저장 서비스는 사용하지 않는다.

공식 근거: [이미지 생성 규격](https://ai.google.dev/gemini-api/docs/image-generation), [가격](https://ai.google.dev/gemini-api/docs/pricing), [Generate Content REST 요청](https://ai.google.dev/gemini-api/docs/generate-content/image-generation).

## 실행·배포 설정

기존 GEMINI_API_KEY를 사용한다. 해당 계정에서 이미지 모델과 결제가 활성화되어 있어야 한다. 실제 유료 생성 결과는 이번 자동 테스트에서 호출하지 않았다.

로컬 기본 저장 경로: 실행 폴더의 data/pocket-backgrounds. Git과 배포 파일에 포함하지 않는다.

서버 권장 설정:

```ini
POCKET_BACKGROUND_DIRECTORY=/var/lib/pocketmm/backgrounds
POCKET_BACKGROUND_ENABLED=true
POCKET_BACKGROUND_MODEL=gemini-3.1-flash-lite-image
```

배포 서비스 예제에는 StateDirectory=pocketmm를 추가했다. 기존 서버의 서비스 파일을 유지한다면 배포 전에 직접 디렉터리를 준비하고 env에 경로를 넣는다:

```sh
sudo install -d -o pocketmm -g pocketmm -m 750 /var/lib/pocketmm/backgrounds
```

이미지 첨부를 위해 Nginx HTTPS 서버 블록에 client_max_body_size 21m이 필요하다. API 이미지 경로는 기존 /api/ 프록시를 사용하므로 공개 파일 경로나 새 정적 location은 필요 없다. 이미지는 Pocket 소유자 인증 후 반환한다. 릴리스 교체/롤백 때 /var/lib/pocketmm를 보존하고 백업에 포함한다.

## 검증

신규 백엔드 검사 10개와 기존 부재 처리 회귀 31개, 프론트 검사 29개 및 프로덕션 빌드를 통과했다. 응답 본문 읽기 제한을 보완한 뒤 관련 제공자 검사 2개도 다시 통과했다.

저장/재시작/사용자 범위, 키워드 매칭, 투명 변환, 부분 성공 재시도, 동시 요청, REST 요청 규격과 이미지 응답 파싱, 외부 Pocket 접근 거부, 202 응답을 검사한다. 프론트 검사는 화면 비율과 기존 걷기 방향을 확인한다. 브라우저에서는 예시 이미지로 기존 두 VRM, 원경 alpha, 같은 방향의 서로 다른 스크롤 속도, 오류 시 기본 배경과 모바일 폭을 확인한다. 예시 화면은 실제 AI 생성 품질 검증으로 취급하지 않는다.
