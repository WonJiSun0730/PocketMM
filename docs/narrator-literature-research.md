## 관찰과 일반화

1. **감정의 간접 표현**: 「동백꽃」의 말과 행동의 엇갈림, 「파티의 끝」의 불편한 대화에서 생활 행동으로 옮겨가는 반응은 감정명을 반복하지 않고도 관계를 읽게 한다. 모든 감정을 숨기지는 않고 필요한 직접 서술을 허용한다.
2. **행동과 신체 반응**: 「메밀꽃 필 무렵」의 이동·도움·몸의 단서는 행동 자체가 관계와 정보를 전한다. 신체 반응을 장식으로 붙이지 않고 현재 하던 일과 연결한다. 새 단서를 임의 생성하라는 지시로 전환하지 않는다.
3. **공간과 감각**: 밤길의 길 폭·경사·물길이 말하는 거리와 행동을 바꾼다. 식탁과 부엌의 배치도 대화 참여에 영향을 준다. 감각은 동선이나 관찰에 기여하는 것만 선택한다.
4. **대사와 침묵**: 대사 다음에 의미 있는 반응이나 다른 행동이 이어질 때 침묵이 기능한다. 매번 시선 회피나 미소를 끼워 넣는 형식을 만들지 않는다.
5. **문장·문단 리듬**: 동작이 이어지는 구간과 풍경·상황을 살피는 구간은 호흡이 다르다. 길이의 고정 규칙 대신 행동·화자·초점 변화에 맞춰 나눈다.
6. **점진적 관계 변화**: 사물의 제공·거절, 상대의 일을 먼저 챙기는 행동처럼 작은 교환이 관계의 맥락을 드러낸다. 서비스에서는 저장된 관계·성격과 사용자의 선택 범위를 먼저 지킨다.
7. **한국어 표현**: 불필요한 대명사와 해설을 줄이고 대사와 행동의 연결을 살린다. 원작 방언·시대 어휘·특정 작가의 문장 패턴은 복제하지 않는다.
8. **장면별 밀도**: 이동과 위험에서는 동작의 명료함, 생활 장면에서는 필요한 사물과 반응을 선택한다. 모든 장면을 로맨틱한 감각 묘사로 채우지 않는다.

## 직접 작성한 짧은 예시

아래는 작품 인용이나 모델 실행 결과가 아니다. 실제 세션의 사실·행동을 추가하는 템플릿으로 사용하지 않는다. 캐릭터가 해당 행동을 할 권한과 맥락이 있을 때만 참고할 수 있다.

- 감정·생활 행동: “칭찬이 끝나자 은서는 펜 뚜껑을 거꾸로 끼웠다. 바로 고쳐 쥐고는 다음 장을 펼쳤다.”
- 대사·침묵: “‘네가 취소한 줄 알았어.’ 민호는 두 장의 표를 나란히 놓았다. 답이 돌아오기 전까지 날짜가 보이도록 손을 치웠다.”
- 전투·공간: “기둥 왼쪽으로 창끝이 들어왔다. 경비는 반걸음 물러서며 방패를 세웠다. 등 뒤의 계단까지는 두 걸음이었다.”
- 휴식·절제: “주전자가 멎었다. 수아는 책갈피를 끼우고 물을 부었다.”

이 예시들은 문학적 우수성의 검증 자료가 아니다. NARRATOR에는 예시 문장을 넣지 않고 일반 원칙만 넣어 세션 사실 오염과 반복 재현을 줄였다. 실제 품질 비교는 별도 시나리오 문서에 정의한다.
