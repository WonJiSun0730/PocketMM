# Pocket 장면: 2D 배경 + 3D 캐릭터

2026-10-12 기본 배경 전환을 구현했다. 방·바닥·가구·램프·화분 등의 3D 배경 메시와 외부 소파 GLB 로딩을 제거했다. 캐릭터의 VRM 로딩, 모델 높이·배치·방향, 픽셀 렌더링, 기존 모델 준비 조건은 유지한다.

## 배경

- 상담실·휴게실·사무실·침실·기본 배경은 frontend/public/backgrounds의 로컬 SVG 이미지다.
- Pocket의 장소 값으로 프리셋을 선택한다. 알 수 없는 장소는 중립적인 기본 배경을 사용한다.
- 배경은 평면 이미지이고, 투명한 WebGL 캔버스가 기존 VRM 캐릭터만 그 위에 표시한다. 배경 이미지 자체에는 3D 조명이나 가구 메시를 사용하지 않는다.
- Pocket 시각의 낮(06~16시), 저녁(17~20시), 밤(21~05시)에 맞춰 배경 색감과 캐릭터 조명을 조절한다. 기기 시간대는 사용하지 않는다.
- 배율은 배경과 캐릭터에 함께 적용한다. 장면 높이와 캐릭터 픽셀 해상도 조절은 유지한다.
- 기존 세션·장소별 이미지 등록 경로는 우선 적용하며, 이미지 로딩 실패 시 기본 장소 프리셋으로 돌아간다.

2026-10-13: [AI 배경·투명 원경과 파일 저장](pocket-ai-backgrounds.md)을 추가했다. 장소별 저장 이미지를 우선하고, 새 장소는 장면을 열 때 자동 생성한다. 생성 배경은 3:2, 화면 가로 1.5배로 표시하며 배경·투명 원경·캐릭터 순서로 쌓는다. 부재 장면은 생성·이미지·모델 준비가 끝나기 전까지 로딩 문구만 표시하고 재생을 멈춘다. 기본 SVG로 대체하지 않는다. 캐릭터 앞을 가리는 배경 가구 깊이 연출은 적용하지 않는다.

## 기본 스탠딩과 대기 동작

기본 스탠딩과 작은 대기 동작을 추가했다. 정규화된 VRM 뼈대로 팔을 내리고 상체의 작은 호흡·흔들림·고개 움직임을 적용한다. 원래 회전을 기준으로 매 프레임 계산하므로 누적 회전하지 않는다. 루트·다리·발·모델 높이·장면 배치는 바꾸지 않는다. 캐릭터별 위상을 달리해서 동시에 같은 동작을 반복하지 않는다.

하나의 최대 30fps 루프로 모든 VRM을 갱신한다. 숨겨진 페이지에서는 갱신을 멈추고, 시스템의 모션 줄이기 설정에서는 정적인 스탠딩 자세를 유지한다. 긴 프레임 간격은 0.05초로 제한하며 장면 해제 시 루프·리스너·VRM 자원을 해제한다. 걷기·뛰기·앉기·전투 동작이나 대화 기반 동작 선택은 아직 포함하지 않았다.

참고 API: [정규화된 VRM 뼈대](https://pixiv.github.io/three-vrm/docs/classes/three-vrm-core.VRMHumanoid.html), [VRM 프레임 갱신](https://pixiv.github.io/three-vrm/docs/classes/three-vrm.VRM.html).

## 검증

프리셋 이미지 존재, 장소 선택, 새벽 포함 시간대 경계에 대한 검사와 프론트 빌드를 통과했다. 브라우저에서 상담실·침실, 낮·밤, 좁은 장면 컨테이너, 이미지 오류 대체 배경, 배율 조절 및 기존 두 VRM의 렌더링을 확인했다. 임시 확인 화면은 배포 코드에 포함하지 않는다.
