# 실 비용 및 체감 테스트

기존 자동 기억 테스트 아래에 별도로 표시되는 개발자용 기능입니다. 두 기능의 저장소·API·실행기는 분리되며, 기존 자동 기억 테스트의 동작과 합성 시나리오는 변경하지 않습니다. 공통 실행기는 입력 길이 선택 옵션만 확장하고 기존 기본값 4000자를 그대로 유지합니다. 실행·원가 계산·체크포인트·영수증·기본 보고서는 기존 QaRunner / QaPipeline / QaSpec.Rate / QaReports를 재사용합니다. 두 종류의 유료 실행은 기존 전역 잠금으로 동시에 하나만 허용합니다.

## 무엇을 재현하는가

선택한 원본 포켓을 읽기 전용으로 스냅샷하여 별도 `target/pocket-qa-experience/exp-*` H2에 복원합니다. 세계·로어·캐릭터 프로필과 대화 예제·실제 등록/등장 상태·플레이어·인트로·현재 상태·기존 메시지와 변형·기억/근거/접근 제한/압축 출처·임베딩 캐시·해당 인물 관계 상태를 복사합니다. 실제 계정 비밀번호/이메일/로그인 이름은 스냅샷에 저장하지 않으며, 복사본에는 로그인할 수 없는 계정 식별자만 만듭니다.

원본에서는 기억 검색을 실행하지 않습니다. 검색이 기억 접근 시각을 갱신하거나 압축을 유발할 수 있기 때문입니다. 복사본의 모든 셀과 행을 원본 스냅샷과 비교하고, 실행 중인 서버와 워커의 대화·프롬프트·기억·시간 해석 구현의 SHA-256을 비교합니다. 검증에 실패하면 유료 호출 전에 중단합니다. 폼을 연 뒤 대화/설정이 바뀌었으면 시작을 거절합니다. 단순 접속 유지 시각 갱신은 이러한 변경으로 취급하지 않습니다.

복사본에서도 실제 WorldRoomDialogueService, PocketDialogueGatewayRouter, OpenAiDialogueGateway, GeminiDialogueGateway 프롬프트 조립, WorldRoomContextBuilder, 하이브리드 기억 검색과 캐시, 압축, 시간 해석, 대화 참여/입퇴장, 사용자 발화 기억 저장 경로를 사용합니다. 선택 모델로 제공자/모델만 바꾸며 응답 문체/길이 규칙과 요청 본문은 유지합니다. 기존 QA의 target-max-output 및 짧은 Persona 지시, 고정 기억 시험 시나리오는 새 테스트에 적용하지 않습니다.

플레이어 대역은 별도 Luna 모델입니다. 원본 플레이어 설명·현재 장면·기존 전체 대화와 이후 대화를 읽고 다음 사용자 발화/행동만 생성합니다. 매번 질문하기, 수동적 동의, 같은 행동 반복, 다른 인물 제어, 과거 사실 날조, 응답을 길게 만들어 달라는 요구를 피하도록 지시합니다. 캐릭터의 비공개 기억은 플레이어에게 전달하지 않습니다. 실서비스 채팅 DTO에는 고정 글자 수 제한이 없으므로 새 모드는 기존 QA의 4000자 입력 제한도 해제합니다. 기존 자동 기억 테스트의 기본 제한은 유지합니다. 실서비스처럼 4000자를 넘는 입력은 기존 기억 저장 서비스의 정책에 따라 새 기억 추출에서 제외될 수 있습니다.

## 시작 전 설정

기존 `app.qa-ui.enabled=true`, 개발자 권한, `app.qa-ui.workspace`, Maven 경로, API 키와 가격표 설정을 재사용합니다. `prod` / `production`에서는 노출하지 않습니다.

기본 OpenAI 세 모델의 최대 출력은 2026-10-16 공식 문서에서 확인해 `tools/experience-qa-model-limits.json`에 포함했습니다. 기본 경로를 자동으로 읽으므로 기존 키와 가격표가 있으면 추가 경로 설정 없이 사용할 수 있습니다. 다른 파일을 쓰려면 선택적으로 지정합니다:

```properties
app.experience-qa.model-limits-file=C:/SpringWork/projectmm/tools/experience-qa-model-limits.json
```

기본값은 Luna/Terra/Sol 각각 최대 출력 128,000토큰입니다. 근거: [Luna](https://developers.openai.com/api/docs/models/gpt-5.6-luna), [Terra](https://developers.openai.com/api/docs/models/gpt-5.6-terra), [Sol](https://developers.openai.com/api/docs/models/gpt-5.6-sol). 별도 모델을 추가할 때는 `tools/experience-qa-model-limits.example.json` 형식으로 공식 스펙에서 검증한 최대 출력량·근거·확인일을 입력합니다. 예제의 null/빈 문자열은 유료 실행을 허용하지 않습니다. **이 값은 모델 검증과 역할별 상한의 유효 범위 확인용입니다. 일반적인 예상량이나 예약액으로 모델의 이론상 최대 출력을 사용하지 않습니다.** 추론 토큰을 포함해 과금될 수 있는 출력 전체를 포괄해야 합니다.

실서비스에 Gemini 키가 설정되어 있으면 동일한 기억 추출·압축·시간 해석·임베딩 모델을 사용합니다. 해당 보조 모델도 기존 가격표에 추가하고 최대 출력 메타데이터를 등록해야 합니다. 텍스트를 생성하지 않는 임베딩 모델은 최대 출력 0을 명시할 수 있습니다. 텍스트 생성 모델의 최대 출력은 양수여야 합니다. Gemini 키는 서버에서 워커 환경으로만 전달하며 파일/명령 인수에 저장하지 않습니다.

가격표는 기존 형식(모델별 input/cached/written/output, largeContextThreshold, largeInputMultiplier, largeOutputMultiplier, source, checkedAt)을 사용합니다. 보조 모델의 가격이 없으면 유료 모드를 숨김없이 비활성화하고 필요한 모델을 표시합니다. 키나 가격, 최대 출력 정보를 소스에 하드코딩하지 않습니다.

먼저 무료 모의 점검으로 데이터 복사와 실행 경로를 확인할 수 있습니다. 유료 호출은 UI에서 모델·턴 수·최대 지출액·동의를 지정해야 시작합니다. 처음에는 짧은 새 실행으로 원본 설정과 대화를 확인한 뒤 긴 실행을 진행합니다. 기존의 불확실한 유료 실행은 재개하지 않습니다.

## 비용과 측정

- 실서비스 비용: 대상 대화 및 초기 장면/장면 설정·기억 추출/압축·시간 해석·임베딩 등 해당 대화 중 발생한 서비스 호출.
- 테스트 운영 비용: 실서비스 비용 + 플레이어 대역 AI 비용. 별도 평가 모델 호출은 기본적으로 없고, 의미 검토는 사람이 수행합니다.
- 요청 전 STARTED, 응답 후 RECEIVED/실패를 로컬 원장에 내구성 있게 기록합니다. 인증 헤더·예외 본문을 기록하지 않습니다. 유료 요청을 자동 재시도하지 않습니다.
- 사용량/가격이 불명확한 호출은 0원으로 처리하지 않습니다. 원장과 UI에 미확인으로 남기고 후속 유료 호출을 중단합니다. 임베딩 등 공급자가 과금 사용량을 응답하지 않는 API도 동일하게 처리합니다.
- 사전 예상은 실제 설정·최근 서비스 대화·기존 응답의 로컬 토큰 추정과 보조 호출 가정입니다. 과거 응답이 없으면 출력 1000토큰을 **추정용 가정**으로만 사용하고 관측값은 미측정으로 표시합니다. 캐시 할인과 서사 진행, 전체 대화를 읽는 플레이어 AI 비용의 증가로 달라질 수 있습니다. 목표 비용에 맞추기 위해 분량을 바꾸지 않습니다.
- 실행 당시 예상액과 기준을 고정 보존하고, 실측 입력/출력·캐시·호출 수·실측 비용과 비교합니다. 최대 지출액은 예상 범위와 별도입니다. 설정한 테스트 역할별 출력 상한까지 예약할 수 없으면 다음 호출 전에 중단합니다. 예상 범위는 보장이 아니며, 최대 예약액은 별도 표시합니다.
- 사용량에 가격표를 적용한 API 비용입니다. 청구서의 세금·환율·별도 계약/티어 차이는 포함하지 않습니다.

본문 글자 수, 입력/출력/캐시 토큰, 모델 HTTP 왕복 시간, 저장·기억 처리 포함 전체 왕복 시간, 대사/나레이션의 대략적 분량, 최소·중앙·평균·최대·분포를 제공합니다. 대사 분량은 인용부호 기반 휴리스틱입니다. 짧음·기존 분량 대비 편중·반복 표현/행동·불완전 응답 상태는 검토 후보이지 자동 품질 실패가 아닙니다.

설정/캐릭터 이탈과 기억의 실제 반영 여부는 자동으로 합격했다고 주장하지 않습니다. 턴별 실제 대화와 기억 주입 근거를 열람하고, 해당 턴에서 설정 이탈/캐릭터 이탈/기억 오류/적절한 짧은 응답 등의 검토 기록을 저장할 수 있습니다. `COMPLETED`는 실행 종료이며 100턴의 서사 품질 합격을 뜻하지 않습니다.

## 결과와 의도적 차이

전체 대화는 순서대로 페이지를 넘겨 조회합니다. 전체 JSON은 실행 원본·설정 스냅샷·구현/모델/프롬프트 버전·호출 원장·분석·검토 기록을 포함합니다. Markdown, 턴/호출/분량·시간 CSV, 설정/실제 요청 프롬프트 ZIP도 내보낼 수 있습니다. 개별 프롬프트는 인증 헤더 없이 `requests/*.json`에 보존됩니다. ZIP의 합산 원본 크기는 64MB로 제한하며 초과 시 서버 폴더의 원본을 이용합니다.

원본과의 차이를 각 보고서에 보존합니다. 격리 H2는 운영 MySQL의 동시성/DB 특성을 완전히 재현하지 않습니다. 부재 진행·접속 임대와 백그라운드 작업, 별도의 수동 이미지 생성 등의 사용자 동작은 자동 실행하지 않습니다. 테스트 전용 타임아웃과 사전 비용 차단은 적용합니다. 별도 테스트 키/프로젝트를 쓰면 실제 서비스와 캐시·한도가 달라질 수 있습니다. 원본 포켓의 지침과 캐릭터를 테스트용 설정으로 대체하지 않습니다.

복사 검증에 실패한 데이터를 임의로 보정하거나 원본을 수정하지 않습니다. 중지/일시정지는 현재 진행 중인 호출 및 해당 턴의 후처리를 마친 뒤 다음 단계에서 반영됩니다. 불확실한 과금은 수동 검토가 필요하며 버튼으로 자동 재전송하지 않습니다.

## 하드캡 정책 hard-cap-v1

- 실서비스와 기존 자동 기억 테스트는 변경하지 않습니다. 이 모드에서만 API 출력 상한을 적용합니다. 나레이션·길이 프롬프트와 reasoning 설정은 그대로입니다.
- 사용자 예산은 확인된 API 비용 + 미정산 예약액 기준 하드캡입니다. 캐시 할인을 예약에 기대하지 않습니다. 잔액 부족 시 상한 축소, 예산 증액, 모델 변경, 자동 재호출을 하지 않습니다.
- 대상 모델 예상량은 최근 캐릭터 응답 12개의 추정 토큰 평균(없으면 1,000), 안전 예상량은 평균×2와 표본 P95+512 중 큰 값입니다. 이후 실제 호출 원장에서도 최근 12개의 해당 역할·모델·용도 출력량으로 예상과 안전 여유를 갱신합니다. 예상량은 최대 지출 보장이 아닙니다.
- 대상 출력 상한은 max(10,000, 기존 최대 응답 추정 토큰×3+512, 안전 예상량), 플레이어 4,096, 기억 추출 4,096, 압축 8,192, 시간 해석 2,048, 기타 보조 4,096입니다. 모델이 허용하는 상한 및 원래 서비스의 더 낮은 명시 상한을 넘기지 않습니다. 이 값은 목표 분량이 아닙니다. 종료까지 고정하며 자동 증액하지 않습니다.
- 입력은 원래 요청과 스키마를 포함해 공급자의 토큰 계수 API(OpenAI responses/input_tokens, Gemini countTokens)로 사전 계수합니다. 계수 실패·미지원·입력 형식 미검증이면 생성 요청을 전송하지 않습니다. 로컬 문자/바이트 추정으로 대체하지 않습니다. 임베딩 모델이 countTokens를 지원하지 않으면 해당 단계에서 안전하게 중단합니다.
- 출력 상한에는 비가시 추론 토큰도 포함합니다. Gemini 정산은 candidatesTokenCount+thoughtsTokenCount를 집계합니다. thinking 설정은 바꾸지 않습니다.
- 예약은 확정한 입력 토큰×최대 입력 단가와 출력 상한×출력 단가로 계산합니다. 입력 단가는 캐시 할인 없이 input/cached/written 중 큰 값입니다. 장문 할증은 계수한 입력이 threshold를 넘을 때만 적용합니다.
- 예약을 디스크에 동기 저장한 뒤 생성 요청을 보냅니다. 확인된 사용량으로 정산한 후 잔액을 해제합니다. 오류·사용량 누락·과금 경계 위반은 예약을 유지하고 모든 후속 유료 호출 및 재시작 자동 재시도를 차단합니다. 비용 미확인 실행의 자동 재개는 지원하지 않으며 별도 검증·정산 없이 새 호출을 보내지 않습니다.
- budget.json, budget-events.jsonl에 실제액, 예약액, 잔액, 예상액, 안전 여유, 다음 계획 호출 최대 예약액, 차단 이유와 상한을 보존합니다. 설정 스냅샷·요청 원문·보고서 ZIP/JSON에 함께 포함합니다. 정산 후 표시된 최대 예약액은 마지막으로 계획한 호출의 값이며 새 호출 준비 시 갱신합니다.
- 공급자의 유효한 사용량·가격 계약에 따른 API 토큰 비용을 보호합니다. 세금·환율·별도 계정에서 발생한 외부 호출은 이 실행 예산에 포함하지 않습니다. 결과가 상한에 잘렸다면 실서비스 재현성 검토 대상이며 정상 완주·품질 합격으로 간주하지 않습니다.
