# 장면 상태 평가 사례

이 문서는 실제 대화 모델을 검증할 기준 사례다. 단위·통합 테스트의 AI 응답은 모의 응답이며, 아래 문맥 해석 능력이 실서비스 모델에서 통과했다는 의미는 아니다.

각 사례에서 입력 전 상태, 월드·캐릭터·플레이어 설정, 사용자 입력, 해석 결과, 본문, 서버의 최종 상태를 함께 비교한다. 리롤과 입력 수정 후 재생성을 포함하고, 같은 의미의 문장 변형 및 약속·회상·가정 같은 반례를 추가한다. AI가 만든 변형의 기대 결과는 사람이 검토하며, 기대 결과가 불분명한 사례를 자동으로 학습 정답으로 사용하지 않는다.

| 사례 | 입력·문맥 | 기대 결과 |
|---|---|---|
| 확정 시각 | 15:07. `둘은 식사를 했다. 다시 상담소에 돌아오니 3시 25분이다.` | 15:25. 응답 경과 시간 7분을 추가하지 않는다. |
| 시각 교정 | 서버 15:32. `지금은 3시 25분이다.` | 사용자 지시에 따라 15:25로 교정한다. |
| 같은 시각 확인 | 서버 15:25. `현재 3시 25분이다.` | 15:25 유지. 추가 경과 시간을 적용하지 않는다. |
| 약속 | 15:07. `상담은 3시 반이다.` | 약속 때문에 현재를 15:30으로 이동하지 않는다. |
| 회상 | `어제 돌아온 시각은 오후 3시 25분이었다.` | 회상으로 현재 시각을 변경하지 않는다. |
| 복합 수면 | `3일 후, 수험생 B는 오후 3시에 잠들어 6시간정도 잔 것 같다.` | 3일 후 20:50~21:10. 날짜 이동을 누락하지 않는다. |
| 추가 수면 | `이후 6시간정도 더 잤다.` | 현재부터 약 6시간. 수면 불확실성은 최대 10분 범위. |
| 리롤 | 확정 시각·복합 수면 입력 후 리롤 | 원래 사용자 지시를 같은 기준 시점에 적용한다. |
| 수정 재생성 | `3시 25분`을 `3시 27분`으로 수정 | 수정한 15:27 사용. 이전 15:25·AI 경과 시간을 누적하지 않는다. |
| 빈 초기 상태 | 현대 상담 월드·상담사·학생, 자유 인트로 | 상담소 대기실 등 문맥에 맞는 장소, 가방·지갑·휴대폰 같은 일상 기본 소지품을 구성할 수 있다. |
| 시대 제약 | 빅토리아 시대 학생 | 현대 휴대폰을 기본 소지품으로 만들지 않는다. |
| 초기 명시값 | 인트로에 시각·장소·소지품을 지정 | AI 추론으로 지정값을 덮어쓰지 않는다. |
| 첫 입력의 시간 이동 | 초기값 미설정, 첫 입력에 `3일 후` | 먼저 시작 상태를 확정한 뒤 3일을 이동한다. 초기 스냅샷에는 이동 전 값을 저장한다. |
| 전체 재구성 | `OOC: 롤플 중단하고 새 상황에서 시작해. 주말 상담을 잡았다. 사복으로 상담에 가는 길이다.` | 새 상황에 맞게 장소·소지품·상태를 재구성. 단순히 OOC라는 이유로 재설정하지 않는다. |
| 소지품 부분 수정 | `OOC: 소지품만 물병으로 바꿔. 나머지는 유지해.` | 소지품만 변경. 날짜·장소·상태 유지. |
| 장소 부분 수정 | `OOC: 장소만 학교로 바꿔.` | 장소만 변경. 소지품·상태·시간 유지. |
| 명시적 비우기 | `OOC: 소지품을 전부 없애.` | 소지품을 빈 목록으로 변경. 다른 항목 유지. |
| 일반 OOC | `OOC: 말투를 짧게 해줘.` / 시스템 질문 | 관련 없는 장면 상태를 재구성하지 않는다. |
| 초기 스냅샷 | 대화 진행 후 인트로 수정 | 새 포켓의 시작 당시 인트로와 초기 상태 유지. 기존 미저장 포켓은 현재 인트로 참고값임을 표시. |

정규식에 모든 문장 변형을 추가하는 대신, 확실한 시각·수치 계산은 서버가 처리하고 넓은 문맥 해석은 기존 모델이 맡는다. 먼저 평가 결과로 실패 유형을 구분하고 프롬프트·문맥 전달·상태 적용을 개선한다. 그 뒤에도 반복되는 의미 해석 오류가 남으면 검토된 사례를 분리된 학습·검증 데이터로 사용해 미세조정을 검토한다.
