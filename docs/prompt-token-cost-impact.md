# 프롬프트 토큰·비용 영향

측정일: 2026-10-16. `PromptTokenImpactTest`가 실제 빌더의 합성 컨텍스트를 o200k_base `countTokensOrdinary`로 계산한다. 원시 결과는 테스트 실행 시 `target/prompt-token-impact.json`에 생성된다. 전송 프레이밍·도구 스키마·모델별 토크나이저 차이를 제외한 **로컬 추정**이며 provider 청구치가 아니다. Gemini의 실제 토큰 수와도 구분한다.

## 단계별 결과

SYSTEM/SCENE 외부화는 정규화 전체 프롬프트의 기존 SHA-256과 일치한다. 내용 이동만으로 토큰 절감이 생기지 않는다. NARRATOR 활성화 전 단계에서 동등성 및 관련 39개 테스트가 통과한 뒤 새 표현 지침을 추가했다.

| 합성 입력 | NARRATOR 이전 | 이후 | 증가 |
|---|---:|---:|---:|
| world stable / 플레이어 통제 허용 | 3,911 | 4,645 | 734 |
| world stable / 엄격 통제 | 3,408 | 4,142 | 734 |
| world dynamic / 두 모드 각각 | 116 | 116 | 0 |
| legacy 전체 system | 5,782 | 6,516 | 734 |
| continuation / strict, LOW, MODERATE, HIGH 해당 6개 입력 | 각 250–488 | 동일 | 0 |
| 구조화 부재 계획 | 2,468 | 2,468 | 0 |

NARRATOR는 world stable과 legacy system에 각각 한 번 들어간다. 같은 world gateway를 사용하는 부재 서사도 적용 대상이다. 부재 **계획 추출**·기억 추출·임베딩에는 소설 표현 지침을 넣지 않는다. 지침 마커·문서 제목은 전송하지 않는다. 실제 세션의 전체 토큰은 세계관·캐릭터 수 등에 따라 달라진다.

## 비용 산식

기존 저장소 `AiUsageTracker`의 입력/캐시 입력 단가를 그대로 이용한 조건부 계산이다. 최신 외부 가격 확인이나 가격 변경이 아니다. 추가 입력 734토큰이 동일하게 청구된다고 가정하며, 출력 토큰 변화·캐시 쓰기·캐시 보관 비용은 포함하지 않는다.

| 모델 | 기존 입력/캐시 입력 단가 ($/100만) | 1회 cold 증가 ($) | 추가분 전체 cache hit 증가 ($) |
|---|---:|---:|---:|
| gpt-5.6-luna | 0.20 / 0.02 | 0.0001468 | 0.00001468 |
| gpt-5.6-terra | 2.00 / 0.20 | 0.001468 | 0.0001468 |
| gpt-5.6-sol | 4.00 / 0.40 | 0.002936 | 0.0002936 |

산식: `734 / 1,000,000 × 해당 단가`. Gemini는 모델별 실제 토큰과 적용 가격을 확인하지 않았으므로 금액을 단정하지 않는다. 실제 대화가 길어지면 출력 비용이 변할 수 있으며 위 값은 전체 응답 비용의 보장값이 아니다.

## 캐시·호출·지연

- 기존 OpenAI explicit cache breakpoint와 stable/dynamic 분리를 유지한다. NARRATOR는 매 턴 같은 위치에 같은 내용으로 조합된다. 수정 배포 시 stable 해시가 한 번 바뀌므로 기존 prefix 재사용을 보장하지 않는다. stable에는 기존대로 캐릭터·세계관 설정이 있어 해당 설정 수정도 캐시 키에 영향을 준다.
- 추가 모델 호출은 0회다. Mock 전송 계수는 각 provider·각 모드마다 기존 역할극 호출 1회다. Gemini의 기존 장애 재시도 정책을 바꾸지 않았다.
- UTF-8 리소스는 초기화 시 한 번 로드해 메모리에 보관한다. 턴별 파일·네트워크 로딩은 없다.
- 실제 생성 지연은 미측정이다. 입력 증가로 처리 시간이 늘 수 있고 출력 길이도 변할 수 있다. Mock 속도나 로컬 토큰 계산 시간을 API 생성 지연으로 해석하지 않는다.
- 이번 검증의 실제 외부 모델 호출과 청구 비용은 0이다. 기존 누적 $4 장부·하드캡 코드는 변경·초기화하지 않았다.
