# Pocket 시간 체크와 부재 활동

## 사용 방법

1. Pocket에서 플레이어를 선택한 후 왼쪽의 **시간 체크**를 ON으로 켠다. 작은 화면에서는 대화 위의 도구 영역에 표시된다.
2. 다른 화면으로 이동하거나 브라우저 탭을 떠난다.
3. 돌아오면 부재 시간을 반영하고, 캐릭터가 한 일의 짧은 목록을 시간순으로 보여준다.

포켓 목록은 최근에 실제 진행된 순서로 정렬된다. 새 포켓 시작, 새 대화 응답, 자동 전개, 리롤·재생성, 부재 활동 반영은 실제 서버 시각을 기록한다. 단순 열람, 접속 기록 갱신, 설정 변경, 이전 버전 선택, 이모지 말풍선 다시보기는 목록 순서를 바꾸지 않는다. 이야기 속 날짜를 과거로 바꾸어도 최근 진행한 포켓이 위에 유지된다. 기존 포켓은 저장된 답변·리롤의 생성 시각을 참고하며 진행 근거가 없는 기존 포켓은 ID 역순으로 뒤에 배치한다.

기본값은 OFF다. 켠 시점부터 계산하며 60초 미만의 부재는 별도 활동을 생성하지 않는다. 한 번에 최대 3일을 반영한다. 현실 날짜로 교체하지 않고 기존 이야기 시각에 경과 시간을 더한다.

화면을 열어 둔 동안에는 30초마다 접속 기록만 갱신한다. 주기적인 AI 활동 생성은 없다. 활동 생성은 복귀 시점에만 요청되며 Pocket에 선택한 AI 제공자와 모델을 사용한다.

## 활동 범위

캐릭터는 기존 롤플보다 조금 적극적으로 산책, 대화, 휴식, 독서, 일, 식사, 커피 같은 일상 활동을 선택할 수 있다. 월드 설정, 캐릭터 프로필, 이전 대화와 Pocket 기억을 참고한다. 활동은 최대 8개이며 등록된 Pocket 캐릭터와 플레이어가 참여한다.

부재 중에는 플레이어 설정과 최근 의도를 참고해 반응·선택을 대신 서술하고 상황을 이어간다. 사용자 응답을 기다리며 멈추지 않는다. 활동으로 바뀐 플레이어 상태만 반영하고 기존 부상·소지품을 근거 없이 제거하지 않는다. 장면을 떠난 캐릭터의 부재 중 활동이 플레이어 장면 복귀를 의미하지 않는다.

예: 공원에서 A와 B가 산책하며 이야기함 → 집에 돌아와 커피를 마심. 짧은 목록과 함께 참여 캐릭터의 머리 위 이모지 말풍선으로 활동을 순서대로 재생한다. 산책 🚶, 대화 🗣️, 휴식 🛋️, 기다림 ⏳, 수면 💤, 독서 📖, 일 📝, 식사 🍽️, 커피 ☕이며 말풍선에는 대사를 넣지 않는다.

새로 생성된 부재 리포트는 활동당 4초씩 한 번 자동 재생한다. 이미 확인한 리포트는 재진입만으로 다시 재생하지 않는다. **활동 다시보기**, **일시정지**, **이전**, **다음**, **현재 장면**으로 조작할 수 있다. 화면을 떠나면 재생 타이머가 멈추고, 채팅을 시작하면 현재 장면으로 돌아온다. 시스템의 움직임 줄이기가 켜져 있으면 자동 재생을 시작하지 않으며 수동 다시보기는 가능하다.

재생은 저장된 활동의 미리보기다. 실제 Pocket의 시각·플레이어 장소·등장인물을 바꾸거나 추가 AI 요청을 보내지 않는다. 활동 장소가 현재 플레이어의 장소와 일치하거나 그 장소 내부의 방인 경우 플레이어 모델과 현재 장면에 남아 있는 인물을 수동 상태로 유지한다. 플레이어가 실제 참여한 활동은 다른 장소여도 플레이어 모델을 표시한다. 참여하지 않은 다른 장소의 활동에는 표시하지 않는다. 활동 이모지는 실제 참여 NPC와 참여한 플레이어에게 표시한다. 모델이 없는 캐릭터는 이름과 이모지 미리보기로 표시한다. 장소 배경은 기존 2D 프리셋을 사용하며 등록되지 않은 장소는 기본 배경을 유지한다.

## 기록과 오류

부재 요약은 대화 기록에도 저장되며 캐릭터별 Pocket 기억으로 연결된다. 요약에는 시각·캐릭터·시스템·플레이어 상태의 전후 스냅샷이 있어, 해당 메시지부터 이후 삭제하면 시각이 복원되고 파생 기억과 활동 리포트도 삭제된다. 부재 요약을 일반 롤플로 리롤하거나 수정하는 것은 허용하지 않는다.

생성 실패 시 이야기 시각과 부재 기준 시각을 변경하지 않는다. **다시 확인**으로 재시도할 수 있다. ON 요청을 반복해도 미처리 부재를 버리지 않는다. 여러 탭에서 동시에 복귀하거나 부재 정리 중 채팅·설정을 변경하는 경우 충돌 응답으로 중복 적용을 막는다.

## API

- `GET /api/worlds/pockets/{sessionId}/progress`: 설정과 최근 리포트
- `PUT /api/worlds/pockets/{sessionId}/progress`: `{ "enabled": true }`
- `POST /api/worlds/pockets/{sessionId}/progress/resume`: 복귀 처리
- `POST /api/worlds/pockets/{sessionId}/progress/presence`: 접속 기록 갱신

모든 요청은 Pocket 소유자에게만 허용된다. 모델 호출은 DB 쓰기 트랜잭션 밖에서 수행한다. 작업 임대는 10분이며 결과 적용과 기록·기억 저장은 하나의 트랜잭션이다. 기존 Pocket의 설정 열은 null일 수 있고 OFF로 해석한다.

## 확인할 테스트

- ON 후 1분 이상 다른 화면을 보고 돌아와 시간과 활동 목록이 한 번 반영되는지 확인
- 이어서 재진입해 같은 부재 활동이 중복 생성되지 않는지 확인
- OFF인 동안 부재 시간이 반영되지 않는지 확인
- 플레이어가 참여한 활동의 장소·소지품·상태 변경이 반영되고, 생략된 상태와 NPC만의 활동은 플레이어 상태를 보존하는지 확인
- 캐릭터 활동이 일상 범위에 머물며 중요한 사용자 선택을 남기는지 확인

자동 통합 테스트는 DB 저장, 실패 후 재시도, 소유권, 3일 상한, 일시정지, 동시 요청, 플레이어 참여·상태 반영·삭제 복원, 구형 일시정지 해제, 기록 삭제와 기억 정리를 검증한다. 실제 모델의 문체와 활동 적절성은 위 대화 테스트로 확인하며 문제 기록으로 사례를 쌓는다.

모델의 물리는 스탠딩 자세·크기·위치 설정 후 초기 상태를 다시 맞추고, 표시 전 짧게 안정화한다. 큰 시간 간격은 작은 물리 단계로 나누어 처리하며 머리카락·날개의 관성 감쇠를 보강한다.

## 기억 갱신의 잠금 충돌 방지

기억 압축은 별도 트랜잭션에서 한 번 저장한다. 회상용 객체는 압축 성공 후 호출 측의 변경 감시에서 분리하여, 접근 기록을 별도 저장할 때 같은 행을 다시 갱신하거나 잠금을 잡지 않는다. 반복 읽기 격리 수준에서도 압축된 회상 내용을 즉시 사용한다. 기존 압축·접근 기록의 독립 저장 정책은 유지한다.

부재 정리 준비 단계에서 DB 오류가 나면 내부 SQL 대신 재시도 안내를 반환한다. Pocket의 시각·부재 기준·작업 임대는 반영하지 않으며 **다시 확인**으로 재시도할 수 있다. 실제 장애 원인은 서버 로그에 보존한다.

## 부재 중 플레이어 자율 활동

부재 중에는 플레이어 프로필·최근 의도·현재 상황을 참고하여 필요한 반응과 선택을 대신 서술한다. 응답을 기다리며 무기한 멈추지 않는다. 일반 채팅의 플레이어 조종 제한과 연속 자동 진행 횟수 규칙은 부재 시뮬레이션에 적용하지 않는다. 기존 일시정지된 Pocket도 다음 복귀부터 다시 진행한다. 이미 저장된 요약은 변경하지 않는다.

플레이어가 실제 참여한 활동은 `playerInvolved`로 구분한다. 참여 활동에서 변경된 최종 장소·상태·소지품만 `playerState`로 반영하고, 생략한 항목은 보존한다. 장소는 마지막 플레이어 참여 활동과 일치해야 한다. 상태 전후 스냅샷은 대화 삭제 시 함께 복원된다.

확인용으로 대화 기록의 부재 활동에도 말풍선과 동일한 활동 이모지를 표시한다. 기다림 ⏳, 깨어 있는 휴식 🛋️, 수면 💤, 요리 🍳, 치료·돌봄 🩺, 이동 🚗를 구분하고 상담·대화는 🗣️를 사용한다. 상황과 무관한 행동으로 전개를 채우지 않고 기존 상담이나 요리 등 현재 행동의 자연스러운 다음 단계와 결과를 요약한다.

## 완료된 장면과 개인 생활의 연속성

최근 대화와 부재 활동의 완료 결과를 다음 활동의 출발점으로 삼는다. 상담 종료→개인 저녁, 식사 종료→헤어짐, 근무 종료→퇴근, 귀가→집에서의 생활처럼 단계가 바뀔 수 있다. 이전 질문·조언·상담을 반복해서 같은 장소에 머물게 하지 않는다. 플레이어의 현재 장소와 행동이 중심이며 NPC의 다른 장소 생활은 보조로 다룬다. 등록된 캐릭터 목록은 동행의 근거가 아니다.

플레이어 단독 활동은 빈 `characterIds`와 `playerInvolved:true`로 저장·재생할 수 있다. 실제 참여한 NPC만 표시하며 플레이어에게도 해당 활동 이모지를 표시한다. 부재 구간을 벗어나거나 겹치는 AI 시각은 서술 순서를 유지한 채 요청 구간 안에 나누어 배치한다. 이때 기록 시각은 서버가 보정한 근사값이다. 정상 시각은 그대로 보존한다.

## 복귀 디스플레이

새 부재 활동이 있고 복귀 처리나 테스트 치트로 새 리포트가 만들어졌을 때만 중앙 디스플레이를 자동으로 연다. 큰 화면의 표시 영역은 300×300px이며 작은 화면에서는 정사각 비율을 유지해 축소한다. 배경은 딤 처리하고 Light/Dark 토큰과 단일 Muted Periwinkle 포인트 컬러를 사용한다. 움직임 줄이기 설정에서는 창은 열되 자동 재생은 하지 않는다.

X 또는 Escape는 창만 닫는다. 재생이 끝나면 마지막 활동을 유지한다. 다시보기는 저장된 같은 리포트를 재생하며 AI를 호출하지 않는다. 자세히 보기는 준비 중인 버튼만 제공한다. 모르는 일이에요는 최신 부재 리포트와 대화·파생 기억을 취소하고 이야기 시각·등장인물·플레이어 상태를 복원한다. 이후에 일반 대화가 진행됐다면 관련 없는 대화를 삭제하지 않고 충돌 안내를 반환한다.
