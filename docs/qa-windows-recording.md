# 로컬 QA 기록 저장 실패

2026-10-21 로컬 실행 `exp-8daf3a60a1508ce0b4b85523`은 7턴 완료 후 다음 턴의 기억 검색 중 중단됐다.
마지막 MEMORY_EMBEDDING 요청은 응답과 입력 35토큰 사용량을 원장에 기록한 뒤
`java.nio.file.AccessDeniedException`으로 실패했다. 마지막 응답의 기록 비용은 $0.0000007이다.
이는 서버 RAM 부족이나 예산 소진으로 확인된 실패가 아니다.

기존 처리에서는 응답 후 비용 상태 저장 실패도 통신 실패와 같은 경로로 처리했고,
같은 호출의 이미 확인된 사용량을 UNKNOWN으로 덮어썼다. 이후 대상 답변 모델 사용량이
없다는 일반 오류가 추가돼 UI에는 비용 미확인 2건으로 표시됐다. 기존 실행 원장은 수정하지 않는다.

수정 후 예산 상태 파일과 경험 QA 상태 파일의 원자적 교체가 Windows 접근 거부를 만나면
해당 로컬 파일 이동만 최대 5회 시도한다. 대기는 25/50/100/200ms이며 API 요청은 반복하지 않는다.
원자적 교체를 지원하지 않으면 일반 덮어쓰기로 우회하지 않고 중단한다.
비용 상태 임시 파일도 교체 전에 동기 저장한다.

응답 사용량을 원장에 저장한 뒤 후속 로컬 저장이 영구 실패하면 기존 사용량을 유지하고
LOCAL_PERSISTENCE_FAILED로 분류한다. 해당 실행은 계속 차단하며 자동으로 새 유료 요청을 보내지 않는다.
응답 자체가 없는 진짜 통신 오류의 미확인 처리와 예산 하드캡 정책은 유지한다.

검증은 모의 HTTP와 임시 파일로만 수행한다. 임시 파일 접근 거부 후 성공, 영구 접근 거부,
원자적 이동 미지원, 응답 뒤 저장 실패 시 사용량 유지 및 요청 1회 유지, 기존 예산 차단을 확인한다.
이 수정은 기존 중단 실행의 자동 재개나 과금 정산 승인을 제공하지 않는다.
