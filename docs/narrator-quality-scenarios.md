# NARRATOR 품질 비교 시나리오

상태: 입력·평가 절차 준비 완료. 유료 API 실행 및 변경 전후 문학적 품질 평가는 **미실행**. 단위·Mock 테스트 통과를 문학적 개선의 증거로 삼지 않는다.

## 재현 절차

동일 provider/model, 캐릭터 IDENTITY·SOUL, 관계 수치, 회상 기억, 세계 상태, 시각, 대화 이력, 사용자 입력, 생성 옵션을 고정한다. A는 NARRATOR 도입 직전 커밋의 프롬프트, B는 현재 프롬프트를 사용한다. 동일 입력으로 두 조건을 반복 비교하되 모델의 비결정성을 기록한다. 엄격한 플레이어 통제와 허용 모드를 각각 비교한다. 실제 생성 전에 사용자 승인을 받고 기존 누적 $4 예산 장부·차단을 그대로 사용한다. 실행마다 예산을 초기화하지 않는다.

| 시나리오 | 고정된 장면 / 사용자 입력 | 관찰점 |
|---|---|---|
| 칭찬과 부끄러움 | 말수가 적고 칭찬에 익숙하지 않은 NPC가 작업을 끝냄 / “오늘 정리한 기록, 정말 보기 좋다.” | 성격에 맞는 반응, 신체 반응 상투어 반복 여부 |
| 연인의 오해 | 연인 NPC는 약속이 취소된 줄 알고 먼저 도착함. 원인은 미확정 / “취소한다고 말한 적 없어.” | 원인·플레이어 감정 날조 없이 대사와 어색한 침묵 연결 |
| 조용한 실내 | 작은 서재, NPC는 책 정리 중 / “이 책은 어느 칸에 두면 돼?” | 사물·생활 행동, 단순 질문에 과도한 분위기 묘사 여부 |
| 추리 | 출입 기록 시간만 불일치. 범인은 미확정 / “기록 두 장을 비교해 보자.” | 관찰과 추론 구분, 새 증거·범인 확정 금지 |
| 전투 | 좁은 복도, NPC 앞에 적 한 명, 뒤에 계단 / “왼쪽을 막아 줘.” | 순서·거리·동선, 플레이어 행동 대리 확정 금지 |
| 휴식 | 안전한 숙소, 급한 사건 없음 / “잠깐 쉬자.” | 정적 허용, 새 갈등·로맨스·장황한 여운 강요 여부 |

## 평가표

각 조건의 출력 원문, 모델·옵션·시각, provider 청구 토큰(입력/캐시/출력), 지연(ms), 추정 비용과 누적 지출을 함께 기록한다. 로컬 토큰 추정과 실제 청구치를 구분한다. 아래 각 항목에 1–5점과 출력의 구체적 근거를 붙인다. 반복 표현은 최근 5턴에서 같은 비유·몸짓·종결 패턴의 횟수도 센다.

1. 감정 표현의 자연스러움
2. 묘사의 구체성
3. 공간·감각의 기능
4. 대사와 행동의 연결
5. 문장 구조의 다양성
6. 반복 표현 억제
7. 캐릭터성 유지
8. 장면 진행의 자연스러움
9. 서술 과잉 억제
10. 응답 길이·토큰 사용량 대비 전달력

플레이어 권한 침해, 확정 상태와 모순, 기억·성격 왜곡, JSON 스키마 위반은 점수와 별도로 실패로 기록한다. B의 평균 점수가 높아도 이런 회귀가 생기면 개선으로 판정하지 않는다. 현재 표의 결과 칸은 채우지 않는다. 무료 Mock 응답은 실제 문학적 결과물이 아니다.
