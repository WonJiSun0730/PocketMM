# 실제 Pocket 채팅 본문 조기 전달

## 동작

PocketPage의 일반 메시지 전송은 POST `/api/worlds/{worldId}/rooms/{roomId}/sessions/{sessionId}/chat/stream`을 사용한다. 소유권과 월드 일치를 확인한 다음 NDJSON 이벤트를 전달한다.

1. `started`: 요청 연결. 본문 생성 전 초기 장면·시간·기존 사실 준비는 기존 순서대로 수행한다.
2. `preview`: 생성된 전체 본문을 로컬 구조 검증 직후 flush한다. 연속성 REVIEW/VERIFY와 기억 저장 완료를 기다리지 않는다. 화면에는 본문과 확인 중 안내를 표시한다.
3. 기존 승인 게이트, 필요 시 수정 후 VERIFY, 사실 근거 검증, 대화 트랜잭션 커밋, AFTER_COMMIT 기억 처리를 수행한다.
4. `complete`: 서비스 프록시 반환 후 확정 본문 전달. 수정본이 다르면 화면에서 수정 사실을 알린다. 저장된 대화·기억·상태를 다시 조회한다.
5. `failed` 또는 연결 중단: 미확정 본문을 제거하고 저장된 대화를 재조회한다. AFTER_COMMIT 실패는 이미 커밋됐을 수 있어 무조건 롤백이라고 표시하지 않는다. 자동 재전송하지 않는다.

## 정확성 및 범위

- QA 전용이 아닌 실제 사용자 Pocket 일반 전송 경로다. 기존 JSON API와 QA 경로는 유지한다.
- UI 조기 표시만 분리한다. 검사 승인·수정 검증·사실 저장·기억 이벤트 순서는 유지한다. 미확정 본문을 신뢰된 사실로 저장하지 않는다.
- 확인 중에는 다음 메시지·수정·리롤을 잠근다. 확정 전 다음 턴을 생성하지 않는다. 여러 브라우저 요청의 기존 DB 세션 잠금도 유지한다.
- 작업은 기존 요청 스레드와 트랜잭션에서 끝까지 수행한다. 별도 비영속 백그라운드 스레드나 재시도 작업을 만들지 않는다. 클라이언트 연결 오류가 유료 호출의 취소·재시도 원인이 되지 않도록 PrintWriter 전송 오류를 생성 경로로 전파하지 않는다.
- ThreadLocal은 HTTP 전달 콜백에만 사용하고 finally에서 해제한다. 모델 설정·검사 정책·추가 유료 호출 수는 변경하지 않는다.
- 글자 단위 모델 스트리밍, 후처리 병렬화, 확정 전에 다음 메시지 보내기, 일반 1:1 ChatPage 및 리롤·계속하기의 조기 전달은 이번 범위에 포함하지 않는다.

## 시간과 비용

기존 57턴 평균 34.6초는 전체 처리 시간이며 생성 호출은 평균 10.5초였다. 이번 변경은 생성 이후 REVIEW/VERIFY 및 저장·기억 처리 시간을 본문 첫 표시 대기에서 제외한다. 생성 전에 수행되는 초기 설정·시간 판단·기존 사실 준비는 여전히 기다린다. 따라서 새 본문 도착 시간이 10.5초라고 보장하지 않는다. 유료 API 또는 실제 배포 경로 지연은 측정하지 않았다. 총 처리 시간과 과금은 본질적으로 동일하며 비용 절감을 주장하지 않는다.

`Cache-Control: no-store, no-transform`, `X-Accel-Buffering: no` 및 이벤트별 flush를 사용한다. 별도 CDN/압축 프록시가 응답을 모으면 조기 표시가 늦어질 수 있으므로 해당 배포 환경에서 확인해야 한다. 서버 종료 전 미확정 preview는 보존 대상이 아니며, 커밋된 원문은 기존 DB에서 다시 조회한다.

## 무료 검증

- 생성 preview가 REVIEW보다 먼저 전달되고, 수정본은 VERIFY 통과 후에만 최종 반환됨을 확인한다.
- 거절·형식 오류는 여전히 실서비스 저장을 차단하고, 실패 후 콜백 범위가 다음 요청으로 새지 않음을 확인한다.
- 컨트롤러에서 서비스 반환 전 응답 flush, 승인된 최종 본문, 실패 시 complete 부재·공급자 정보 비노출·단일 호출, 월드 불일치 시 생성 미호출을 검증한다.
- 기존 실제 H2 월드라인 통합 테스트 13개로 대화·상태·사실 스냅샷 동작을 검증한다.
- 프론트 파서는 한글 UTF-8 바이트 분할, preview 선행 전달, 완료 없는 EOF, 실패·비정상 프레임을 검증한다.
- 유료 API 호출 및 사용자 QA 자동 재개는 하지 않는다.
