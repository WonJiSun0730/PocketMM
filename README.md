# PocketMM · 포켓밀리

PocketMM은 직접 만든 세계관과 캐릭터로 이야기를 이어가는 AI 창작 플랫폼입니다. 월드의 설정과 도입부를 공개하면 다른 사용자가 자신의 플레이어 프로필로 독립적인 이야기 세션인 ‘포켓’을 시작할 수 있습니다.

[프로젝트 소개 발표자료 (PowerPoint)](docs/PocketMM_Project_Introduction_visual_final.pptx)

## 주요 기능

- **월드 제작과 공개** — 세계관, 캐릭터, 도입부, 규칙을 구성하고 표지와 태그를 붙여 공유합니다.
- **다중 캐릭터 대화** — 세계관, 인물의 말투, 현재 장면과 플레이어 상태를 바탕으로 소설형 응답을 생성합니다.
- **응답 재생성과 편집** — 응답 버전과 장면 상태를 함께 관리해 선택한 전개를 다음 대화에 반영합니다.
- **장기기억과 장면 연속성** — 기억의 출처를 보존하고 벡터·어휘 검색으로 관련 기억을 불러옵니다. 인물, 소지품, 사건의 완료 상태는 장면 사실로 관리합니다.
- **부재 중 활동** — 복귀 시 경과 시간에 해당하는 활동을 한 번 반영하고, 타임라인과 별도의 회고 서사로 확인할 수 있습니다.
- **캐릭터 표현** — Three.js 기반 VRM 캐릭터, 활동별 동작, 반응형 화면과 움직임 줄이기 설정을 지원합니다.

## 장기 대화 QA 및 개선

발표자료에 기록된 2026년 10월 21일 시나리오에서 **100턴 중 100턴을 완료**했고, 사용량이 미확인된 호출은 **0건**이었습니다. 장부 기준 서비스 호출 합계는 **$3.3494**, 테스트 플레이어까지 포함한 총비용은 **$4.3565**였습니다. 이 실행에서 후반부 사건 목표 약화, 절차 묘사 반복, 인물과 소지품 상태 혼선을 개선 과제로 확인했습니다.

같은 합성 입력으로 연속성 검사 요청 형식을 비교한 결과, 로컬 추정 입력 토큰이 **6,801개에서 1,954개로 71.3% 감소**했습니다. 실제 서비스 청구 비용은 별도 지표입니다.
